# 出师吧 Prentice

**实习之前，先来练一遍。** 一个在浏览器里做"数据分析实习"的 SQL 练习平台：学生用 SQL 完成模拟业务方提出的分析任务，AI 导师只给提示、不给答案，做完的项目可以整理成简历上的项目经历。

> 在线体验：部署后补充链接
> 作者：蒋佳宇（Leo）｜独立完成市场调研、PRD、产品设计、原型开发和市场营销策略

---

## 这个项目里有什么

|               |                                              |
| ------------- | -------------------------------------------- |
| **95 道练习题**   | 第 0–7 关语法题由浅到深，第 8 关是 8 个两步业务项目；全部免费         |
| **100 个实习项目** | 19 个行业，难度 ★2–★5，按"描述 → 拆解 → 归因 → 结论"完成一张业务工单 |
| **项目引擎**      | 自动生成埋了原因的业务数据和每一步的参考 SQL；VIP 可以定制一套只属于自己的数据  |
| **AI 导师**     | 提示分三级、答对后追问业务含义、给项目结论打分；Key 只放在服务器端          |
| **讨论区**       | 每道题、每个项目都有讨论区，置顶的官方题解要做完才能看                  |
| **激励与增长**     | 学习宠物"统子"、任务仪表盘、能力画像、咖啡返利、邀请同学                |

一个项目的完整流程：

```mermaid
flowchart LR
    A["打开工单<br/>业务方：9 月北京订单少了"] --> B["描述<br/>掉了多少"]
    B --> C["拆解<br/>按用户类型、区域"]
    C --> D["归因<br/>优惠金额变化 · 排除配送时长"]
    D --> E["结论<br/>写给业务方"]
    E --> F["AI 评分<br/>+ 项目海报 / 简历描述"]
```

## 技术实现

| 部分  | 选择                                                                                |
| --- | --------------------------------------------------------------------------------- |
| 前端  | 原生 JavaScript 单页应用，零构建、零依赖                                                        |
| 数据库 | [sql.js](https://github.com/sql-js/sql.js)（SQLite 的 WebAssembly 版），练习数据在浏览器内生成和运行 |
| AI  | DeepSeek API，通过边缘函数转发，前端拿不到 Key                                                   |
| 部署  | 腾讯 EdgeOne Pages；不依赖任何境外资源，国内可访问                                                  |

```
├── public/                 网站本体
│   └── assets/
│       ├── app.js          页面与交互
│       ├── data.js         练习数据库、95 道题、项目引擎
│       ├── discuss.js      内测期示例讨论（界面标注"示例"）
│       └── app.css         视觉样式
├── functions/api/chat.js   AI 导师接口：拼提示词、限流、防泄题
├── docs/                   产品文档
├── scripts/gen-catalog.cjs 自动生成内容清单
└── server.mjs              本地预览服务器
```

**本地运行**

```bash
cp .env.example .env      # 填入自己的 DeepSeek Key；不填也能用，AI 导师会切换到内置提示
node server.mjs           # 打开 http://localhost:8787
```

- AI 生成的简历描述会注明"基于模拟数据"。
